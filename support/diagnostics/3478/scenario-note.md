Input stops before both minute 14 of the episode and minute 79 of the job; the remaining minute joins owned processes. The environment owns continuous video and final evidence collection.

The controller observes native window frames through the read-only compositor oracle. Before each click it records the actual host SDL client bounds and Mutter DisplayConfig state, and requires one origin-zero, scale-one, untransformed physical/logical monitor with exact client-to-mode dimensions. It clicks native frame headers to establish focus. Semantic controls use AT-SPI window coordinates plus the compositor's observed native client origin. Every action requires actual target-PID compositor focus before and after input. The control's real successful tab, edit, and token observations qualify these coordinate assumptions; an unavailable or ambiguous tree blocks the episode.

If it is on, the controller physically presses Num Lock through QEMU and requires a fresh false observation. GNOME settings are retained for context. No clipboard reader or temporary GTK window participates in this check.

The working control types a unique ordinary token into real GNOME Text Editor and copies it with Ctrl+C. LocalSend receives Ctrl+V with an empty, visibly verified Send selection. Opening its real **Edit** control must expose the same token in the selected message. Missing content or accessibility means inconclusive control evidence, not a file-specific failure.

It copies the only file in a real Nautilus directory with Ctrl+A and Ctrl+C, physically focuses LocalSend, verifies Num Lock off, and presses Ctrl+V. Before/after pixels, semantic selection details, process identities, input timestamps, and native protocol traces are retained.
